Exactly ONE bounded session, and archive incoming executable prompt verbatim where obtainable. Conduct source-first novelty screens and preserve negative evidence. Close with validated changes, GitHub PR/green hosted checks, verified remote SHA and standalone successor prompt; never execute successor concurrently. No email, journal/arXiv/Palomar submission, payment, public outreach, rename or child creation without specific human permission. No `sorry` or `admit`, no unexamined `axiom`, no `native_decide` in claimed final Lean proof chain. Any formal theorem needs exact semantic statement, pinned toolchain, `lake build`, `#print axioms`, independent audit and actual Actions success. Mark uncertain source status explicitly.
