# Universal session protocol

START: pin live remote main SHA, branches/PRs/Actions and current governing files; reconcile newest owner instruction; verify unique session ID. EXECUTE: exactly one bounded approved obligation, contemporaneous source/novelty gate, immutable experiment specs and failures, no unsourced theoretical claims, no unapproved external action. CLOSE: precise report + status/claim/decision/novelty update, archive exact input when available, full successor prompt, tests, commit/PR, inspect actual hosted jobs, merge only if required checks green, confirm remote main SHA and PR state. Every fifth substantive session includes progress/correction audit; every tenth adds strategic reassessment; trigger earlier if churn. All independent child paper repositories inherit these rules. Numerical sessions must record population, symmetries, versions, seeds, workflow run/job IDs, artifacts, hashes, controls, limitations and holdouts.
