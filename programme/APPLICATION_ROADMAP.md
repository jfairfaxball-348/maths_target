# Usefulness roadmap

Existing relation: Janzer et al. 2026 demonstrate applications of quantitative delta-system methods to restricted intersection problems and discuss quantum shadow tomography. This does not prove a new P001 result would reduce tomography runtime. **P001:** examine extraction algorithm inputs as explicit k-uniform hypergraph incidence lists, witness certificates (m petals), work/storage complexity and tightness. **P002:** internal vs external witness requirement for recursive embeddings, relevant to extremal graph constructions. **P003:** test whether a new bound genuinely improves a published parameter regime. **FINAL:** broad extremal lemma; application efficacy requires separately proved reductions and complexity measurements. A theorem of existence does not imply efficient construction.
